# Known limitations and support boundaries

This is an MVP preview / pre-release. Known limitations include incomplete
polish, compatibility risk across Antigravity updates, remaining CDP fallback
paths, and the need for owner-controlled real-phone acceptance. The current
snapshot may retain documented bugs.

Support is limited to reproducible issues against the documented toolchain and
an approved Antigravity version. Do not report private conversation contents,
credentials, certificates, or screenshots in public issue systems. This private
repository does not promise hosted support, uptime, backward compatibility with
all Antigravity versions, or production suitability.
