# Contributing

This is a public preview project. Contributions are welcome through GitHub
issues and pull requests. Keep changes narrow, document behavior changes, and
do not include private conversations, screenshots, uploads, logs, credentials,
certificates, signing material, or machine-specific paths.

Before opening a review, run the Node and Flutter checks in
[Development and verification](docs/development.md), plus the repository secret
and privacy scan. Do not claim acceptance from automated checks alone: real
phone and Antigravity verification remains a separate owner-controlled step.

Changes touching Antigravity RPC or DOM compatibility must explain the observed
surface, the compatibility risk, and the fallback behavior. These internal
surfaces are not stable public APIs.
